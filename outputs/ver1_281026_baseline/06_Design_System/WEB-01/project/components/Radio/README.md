Nhóm Radio MUI: vòng 20px viền `control-border`, khi chọn vòng + chấm màu `control-checked` (xanh lá `$ad-green-color`), nhãn 16/24 `text-high`, xếp ngang (gap 16px) hoặc dọc.

- **Consumer cung cấp**: `label`, `required`, `options` (nhãn tiếng Nhật), `value`, `column`.
- Dọc khi ≥ 3 lựa chọn dài (「商品のタイプ」 6 lựa chọn trên SC-036); ngang cho cặp 「あり / なし」「公開 / 非公開」「表示 / 非表示」.
- Cảnh báo: `control-checked` trên nền trắng tương phản thấp (xem usage token) — giữ nguyên như hệ thống.
