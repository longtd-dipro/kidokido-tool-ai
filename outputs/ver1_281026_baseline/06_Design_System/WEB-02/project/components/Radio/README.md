Nhóm radio ngang: icon 25px (`radio-unchecked` màu `icon-muted`, `radio-checked` màu `radio-checked`), nhãn 18px/24px/500 `text-high`, các lựa chọn cách nhau `space-32`.

- **Consumer cung cấp**: `options` (mảng nhãn), `value`, `label` (nhãn nhóm cho a11y).
- Dùng cho 「性別」 (男性 / 女性 / 回答しない) và 「ボーネルンドからの情報を希望する」 (希望する / 希望しない).
- Màu đã chọn `radio-checked` chỉ đạt 1.48:1 trên `surface` — giữ đúng hệ thống, luôn kèm nhãn chữ.
