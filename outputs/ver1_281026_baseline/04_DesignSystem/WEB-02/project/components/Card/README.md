Khối nội dung, 3 tông: `raised` (nền `surface`, bo `radius-lg` 12px, bóng `shadow-raise`, padding `space-40`) · `tinted` (nền `surface-subtle`, góc vuông, không bóng) · `disabled` (nền `surface-disabled`, bo `radius-md`).

- **Consumer cung cấp**: `title`, `tone`, `children`.
- `raised`: 2 card 「当日利用」「予約・オンライン購入」 trên nền `surface-cream` ở trang chủ. `tinted`: card cửa hàng ở 店舗一覧. `disabled`: card vé đã hết hạn ở 「フリーパスの確認」 kèm `Badge`.
- Không dùng ảnh cửa hàng thật trong mẫu thiết kế.
