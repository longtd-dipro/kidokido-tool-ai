Icon SVG vẽ bằng `currentColor`, mặc định 24px: 9 icon Material (tô đặc) + `calendar` (nét 1.5px) + `new-window` (khung 10px) + `circular-progress` (spinner nét 3.6).

- **Consumer cung cấp**: `name` (`IconName`), `size`, `label` (bắt buộc khi icon đứng một mình, vd. 「パスワードを表示」).
- Màu theo ngữ cảnh: `icon-default` trong ô nhập, `primary-text` cạnh link / breadcrumb, `on-primary` trên nền `primary`.
- Kích thước: 20px trong phân trang / breadcrumb / ô nhập nhỏ, 24px mặc định, 25px cho radio.
